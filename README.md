# AI Voice Assistant

An intelligent AI-powered voice assistant built using Python that can interact with users through voice commands, process speech input, and perform automated tasks efficiently.

## Features

- Speech recognition
- Text-to-speech response system
- Voice-based interaction
- Modular Python architecture
- Database integration
- Flask-based web interface
- Simple and responsive UI

## Tech Stack

- Python
- Flask
- HTML/CSS
- JavaScript
- SQLite
- SpeechRecognition
- pyttsx3

## Installation

Clone the repository:

```bash
git clone https://github.com/kailash6207/AI-Voice-Assistant.git
```

Move into the project directory:

```bash
cd AI-Voice-Assistant
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
